# Sales Dashboard Power BI

## Overview
Interactive Power BI dashboard designed to analyze sales performance, product categories, customer activity, and country-based insights through dynamic visualizations and KPI tracking.

## Features
- Interactive KPI cards
- Sales analysis by product
- Product category distribution
- Country-based filtering
- Date filtering and timeline analysis
- Dynamic charts and visualizations
- Power BI data modeling
- DAX measures and calculations

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization
